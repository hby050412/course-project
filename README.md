## 快速体验

1. 登录后进入「日志源管理」→ 新建模拟器（建议：SSH 暴力破解，速率 50，时长 10 秒）
2. 点「启动」→ 回到「日志」页开启「实时流」→ 看日志实时滚动
3. 打开「**告警**」页 → 规则告警自动产生（同源同规则合并计数，×N 徽章）
4. 打开「**机器学习**」页 → 点「开始训练」→ 自动检出异常 IP（含"为什么异常"特征解释）→ 生成 ML 告警
5. 点开任意告警 → 查看证据/特征分析 → 点 **AI 研判**（需在设置页配置 DeepSeek key）→ 获取危害/根因/处置建议
6. 打开「**规则**」页 → 用**规则测试工具**粘贴日志即时验证命中；可新建/启停规则
7. 回到「仪表盘」→ 看主被动态势（被动告警 / 主动发现 / 已被实际攻击 / ML 异常）
   + 攻击时间线 / **来源 IP 地图**（按省份聚合）/ 归属类别占比 / TOP 攻击源 / 级别占比
8. 打开「**主动扫描**」页 → 添加目标 `http://127.0.0.1:5050` → 点「开始扫描」→ 查看结果：
   信息收集（指纹/响应头/robots/目录）+ 15 条漏洞发现（6 类检测器，含 payload、响应证据与修复建议）
9. 打开「**报告**」页 → 选择扫描任务 → 「生成 HTML 报告」→ 在线查看 / 下载；
   报告页按 <kbd>Ctrl+P</kbd> 可直接另存为 PDF（样式已做打印适配）
10. **主被动闭环演示**（答辩重点）：扫描任务详情页点「⚡ 模拟攻击（闭环演示）」
   → 平台针对刚发现的漏洞生成攻击流量 → 走真实规则引擎产生告警
   → 每条漏洞卡片显示「已在日志中检出 N 条针对该地址的攻击」
   → 到告警详情页可见「关联的扫描发现」，形成 扫描发现 → 攻击发生 → 日志告警 的闭环

> **靶场启动**（主动扫描的验证目标，先在另一个命令行窗口运行）：
> `.venv/Scripts/python.exe target_lab/app.py` → http://127.0.0.1:5050
> 靶场含预置漏洞：SQL 注入 ×4（含过滤绕过变体）/ 反射型 XSS ×2 / 目录遍历 / 敏感文件泄露 ×3（含后台暴露）
> / 安全头缺失与配置不当 / 过期组件（jQuery 1.12.4）—— 共 15 条发现
> 🔒 平台内置授权控制：只允许扫描 `config.py` 中 `SCAN_ALLOWED_HOSTS` 登记的主机（默认仅本机靶场）

> - 演示样例文件：`data/raw_logs/sample_mixed_100.log`（100 行混合攻击日志，导入后产生 20+ 条各类告警）
> - 数据集实验：`.venv/Scripts/python.exe tests/experiments/run_dataset_eval.py`（需先下载 NSL-KDD 到 data/datasets/）
> - 误报率实验：`.venv/Scripts/python.exe tests/experiments/run_fp_eval.py`（1.19 万条语料 → docs/experiments/fp_eval.md）

## 主被动结合的技术实现（论文核心）

一份攻击知识，三处共用 —— 定义在 `secplat/engine/patterns.py`：

| 使用方 | 用法 |
|---|---|
| ① 模拟器 | `ATTACK_REQUESTS` 生成攻击流量（web_attack 剧本 / 闭环演示的定向攻击） |
| ② 被动规则引擎 | 同一文件里的 `*_PATTERN` 正则检出上述流量 → 告警 |
| ③ 主动扫描检测器 | 同一套攻击知识构造探测负载（`audit_payloads()` 保证载荷必被对应正则命中） |

由此形成可验证的闭环（`secplat/engine/correlation.py`）：

```
主动扫描发现漏洞（/product.php 存在 SQL 注入）
        ↓ 攻击者利用
被动日志检出同类攻击（同路径 + 同攻击特征 + 时间窗三层收敛）
        ↓
告警 ←→ 扫描发现 双向关联（告警详情页可反查"这个点我们扫出过漏洞吗"）
```

> 变更攻击知识只需改 `patterns.py` 一处，模拟器、规则引擎、扫描器同步生效。

## 项目结构

```
security-platform/
├── app.py              入口（python app.py 启动）
├── config.py           配置（数据库/端口/会话/登录安全）
├── secplat/            主包
│   ├── models.py       14 张数据表（SQLAlchemy ORM）
│   ├── blueprints/     页面蓝图（auth/logs/alerts/rules/ml/scanner/report/settings）
│   ├── engine/         被动检测引擎（日志解析/模拟器/规则/告警/ML/关联）
│   ├── scanner/        主动扫描链路（信息收集/漏洞检测器/报告）
│   ├── ai/             大模型智能研判（DeepSeek）
│   ├── utils/          工具（实时流/时间/IP）
│   ├── templates/      页面模板（Jinja2）
│   └── static/         静态资源（Bootstrap/ECharts 本地引入）
├── data/               运行时数据（app.db/日志文件/报告/模型，不入版本库）
├── tests/              单元测试（每模块独立 + smoke.sh 一键冒烟）
├── target_lab/         本地靶场（含预置漏洞的测试小站，M4）
└── docs/               论文素材/截图/演示脚本/实验报告
```

> 说明：主包名为 `secplat` 而非 `platform`——避免与 Python 标准库模块 `platform` 重名冲突。
